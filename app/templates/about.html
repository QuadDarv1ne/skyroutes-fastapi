О проекте SkyRoutes

🚀

Что это

SkyRoutes — заготовка сервиса поиска и бронирования авиабилетов на FastAPI. Асинхронная SQLAlchemy, JWT-аутентификация, REST API, Jinja2-шаблоны, Docker и pytest-тесты. Полностью на русском языке.

🛠

Технологии

FastAPI 0.115, SQLAlchemy 2.0 (async), Pydantic v2, JWT (PyJWT) + bcrypt, SQLite/PostgreSQL, Jinja2, Docker, pytest + httpx. Архитектура модульная: каждый домен (auth, flights, bookings, admin) — отдельный роутер.

📊

Возможности

Поиск рейсов с фильтрами и сортировкой, бронирование до 9 пассажиров, классы обслуживания (эконом/премиум/бизнес/первый), админ-панель со статистикой и популярными направлениями, управление рейсами через REST API.

🔐

Безопасность

Пароли хешируются через bcrypt, доступ к защищённым эндпоинтам — через JWT-токен (Bearer для API, httponly-cookie для HTML). Админ-эндпоинты требуют флаг is_admin=True.

🧪

Тестирование

16 pytest-тестов покрывают auth, бронирования, поиск рейсов и edge-cases. Дополнительный smoke-тест в scripts/test_api.py поднимает uvicorn и проходит все сценарии за один запуск.

📦

Развёртывание

Локально через venv, в Docker через docker compose up --build, в проде — через PostgreSQL (меняется только DATABASE_URL). Логирование в stdout, ошибки логируются с трейсбэком, для API возвращается JSON-ответ.
