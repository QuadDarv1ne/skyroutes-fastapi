Частые вопросы

Как изменить данные пассажира в брони?

Откройте бронирование на странице «Мои бронирования» по PNR-коду или email. Для изменения данных пассажира обратитесь в поддержку — изменения вносит только оператор.

Как отменить бронирование?

Перейдите на страницу бронирования и нажмите «Отменить». Места вернутся в рейс автоматически. Статус изменится на cancelled.

Поддерживаются ли разные классы обслуживания?

Да: эконом (×1.0), премиум (×1.4), бизнес (×2.5), первый (×4.0). Цена рассчитывается автоматически при бронировании.

Можно ли использовать API в своём приложении?

Да, REST API полностью открыт. Смотри документацию на /docs. Для защищённых эндпоинтов нужно получить JWT-токен через /api/auth/login.
